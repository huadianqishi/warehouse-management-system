# 推 GitHub 操作步骤（第一个项目：仓储系统 WMS）
# 在 Windows 上按顺序执行（PowerShell / Git Bash 均可）。
# 工作目录：D:\BaiduNetdiskDownload\2026.5.12\Idea

# 1. 进入项目目录
cd "D:\BaiduNetdiskDownload\2026.5.12\Idea"

# 2. 初始化 git 仓库
git init

# 3. 设置默认分支名（可选，统一成 main）
git branch -M main

# 4. 添加所有文件（.gitignore 已生效，target/ .idea/ application-local.yml 不会进）
git add .

# 5. 提交前【务必】检查这次要提交的文件里有没有漏掉的敏感信息：
#    - target/ 编译产物（应被忽略）
#    - application-local.yml（应被忽略）
#    - 任何含真实密码/密钥的文件
git status
#   👉 用眼睛扫一遍列出的文件，确认没有敏感文件。

# 6. 首次提交
git commit -m "feat: 仓储管理系统后端初始提交（密钥外部化，本地配置已忽略）"

# 7. 在 GitHub 网页 New repository 建一个【空】仓库（不要勾选生成 README），
#    比如：warehouse-management-system
#    然后关联远程并推送：
git remote add origin git@github.com:你的用户名/warehouse-management-system.git
#   若用 HTTPS：
#   git remote add origin https://github.com/你的用户名/warehouse-management-system.git
git push -u origin main

# ============================================================
# 本地怎么把真实密码加回来（不进 git）：
#   src/main/resources/application-local.yml 里已放了占位真实值，
#   启动时激活 local profile 即可（IDEA：修改 Active profiles 填 local；
#   或命令行：mvn spring-boot:run -Dspring-boot.run.profiles=local）
#   若不想用 profile，也可把真实值设成系统环境变量 DB_PASSWORD / JWT_SECRET。
